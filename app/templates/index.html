☁️ Panduan Deploy 24/7 ke VPS / Docker

Langkah mudah menjalankan bot ini non-stop 24 jam sehari di server cloud.

Metode 1: Menggunakan Docker Compose (Paling Praktis) 
docker compose up -d

Folder user_data sudah otomatis di-mount sebagai volume sehingga sesi login dan database tidak akan hilang saat server restart.

Metode 2: Menggunakan Systemd / PM2 di VPS Ubuntu 
# Jalankan setup otomatis
./setup.sh

# Jalankan 24/7 di background dengan PM2
pm2 start run.sh --name "tiktok-auto-dm"
🔒 Keamanan Sesi: Sesi browser disimpan di direktori user_data/browser_profile. Begitu Anda scan QR sekali lewat Live Preview, bot akan mengingat login Anda secara permanen.
